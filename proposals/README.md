# Propositions

Chaque proposition sera décrite dans un fichier JSON versionné : identifiant, composant et chemin source, titre, problème observé, intention de design, statut, commit source de référence et lien éventuel vers une revue.

Statuts : `brouillon`, `soumise`, `en-discussion`, `integree`, `refusee`.

Les propositions se préparent avec Codex. Leur intégration au dépôt de l'équipe reste une décision des développeurs.
