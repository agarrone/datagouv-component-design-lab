# GitHub / Primer — liens et panneaux

Référence d’interaction ajoutée le 22 octobre 2026, à combiner avec la proximité visuelle DSFR. Il s’agit d’une interprétation pour le laboratoire, pas d’une reproduction exacte de GitHub.

- [Primer Link](https://primer.style/product/getting-started/rails/components/link/) : liens natifs, style et soulignement selon le contexte.
- [Primer Popover](https://primer.style/product/components/popover/guidelines/) : information contextuelle ancrée à un déclencheur.
- [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines) : focus visible, navigation par vrais liens, états interactifs plus contrastés.

Décisions retenues : navigation textuelle soulignée ; destination externe indiquée une seule fois avec une icône outline ; aperçu riche ouvert au clic par un bouton neutre sans soulignement, état ouvert persistant et fermeture par Échap/clic extérieur. Les aperçus riches restent distincts des infobulles d’aide brèves affichées au survol. Les couleurs et géométries restent celles des fondamentaux du laboratoire.
